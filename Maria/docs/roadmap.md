# Roadmap

This file is reserved for future version planning.

Version 0.1 does not implement roadmap features. Candidate future areas may
include richer reasoning, additional tools, a user interface, voice support, and
plugin-like extensibility, but these are intentionally out of scope for the
foundation release.

Before adding roadmap items to implementation, confirm that they preserve
Maria's principles: simplicity, maintainability, readability, modularity, and
reliability.
