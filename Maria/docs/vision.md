# Vision

Maria is a modular personal AI assistant designed to evolve over many years.

The project should grow from a stable foundation instead of accumulating
short-lived experiments. Each release should make Maria easier to understand,
safer to operate, and simpler to extend.

## Guiding Ideas

- The user remains in control.
- Destructive actions require explicit confirmation.
- Important actions are logged.
- Modules have clear ownership.
- Small reliable capabilities are better than broad unreliable behavior.

Version 0.1 establishes the structure, boundaries, and habits that future
versions will build on.
